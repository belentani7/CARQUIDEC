## 4️⃣ CHECKLIST: Carga Cognitiva + Accesibilidad + Inclusión LGBTQ+

### ✅ Carga Cognitiva Mínima (Basado en WCAG 2.2 + neurociencia cognitiva [[41]][[42]])
- [x] **Chunking**: Máximo 3 ideas por bloque visual. Separación clara con espaciado generoso.
- [x] **Jerarquía visual**: Títulos H1-H3 con contraste 4.5:1 mínimo. Sin más de 3 niveles de encabezado por página.
- [x] **Revelación progresiva**: Contenido complejo (ej: teoría del estrés minoritario) se expande bajo demanda (`<details>`).
- [x] **Ejemplos antes que teoría**: Cada concepto abstracto va precedido de un ejemplo concreto y relatable.
- [x] **Sin metáforas confusas**: Evitar "lucha", "batalla", "superar". Usar "navegar", "construir", "ajustar".
- [x] **Ritmo de lectura ajustable**: Botón para aumentar espaciado entre líneas (+25%, +50%) sin romper layout.

### ✅ Accesibilidad WCAG 2.2 AA + Neurodiversidad [[41]][[43]]
- [x] **Contraste**: Texto/fondo ≥ 4.5:1 (AA), ≥ 7:1 para texto pequeño (AAA opcional).
- [x] **Navegación por teclado**: Todos los elementos interactivos accesibles con Tab/Shift+Tab, foco visible.
- [x] **Lectores de pantalla**: ARIA labels en botones, landmarks (`<main>`, `<nav>`), texto alternativo descriptivo en imágenes.
- [x] **Reducir movimiento**: Preferencia `prefers-reduced-motion` respeta animaciones sutiles o las desactiva.
- [x] **Autenticación accesible**: Sin CAPTCHA visual. Alternativa de verificación por email o pregunta de seguridad [[41]].
- [x] **Enlaces claros**: Texto de anclaje descriptivo ("Ir a técnicas de grounding" vs. "clic aquí").

### ✅ Inclusión LGBTQ+ Afirmativa + Trauma-Informed [[1]][[11]][[12]]
- [x] **Lenguaje afirmativo**: "Personas trans" (no "transgéneros"), "pareja" (no "novio/a" por defecto), pronombres variables.
- [x] **Interseccionalidad explícita**: Ejemplos que incluyen juventud LGBTQ+ racializada, migrante, neurodivergente, con discapacidad.
- [x] **No patologizante**: Nunca "trastorno", "síntoma", "paciente". Usar "experiencia", "herramienta", "persona".
- [x] **Advertencias de contenido opcionales**: Toggle en configuración para activar avisos antes de contenido sensible (rechazo familiar, ideación suicida).
- [x] **Validación de experiencias**: Frases como "Esto es real. No es exageración. Tu reacción tiene sentido."
- [x] **Enfoque en fortalezas**: Cada mención de riesgo va acompañada de factores protectores y estrategias accionables.
- [x] **Privacidad por diseño**: Sin tracking de identidad, sin nube obligatoria, opción de usar sin cuenta.
