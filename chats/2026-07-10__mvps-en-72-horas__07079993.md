### 1. Generación del Producto: **Zero-Day Launchpad**

Basado en el concepto de la agencia, el producto no es solo el "servicio" en sí, sino una **plataforma de productización (Productized Service)** que permite a los clientes solicitar, pagar y trackear su MVP de forma automatizada.

**Nombre del Producto:** Zero-Day Launchpad
**Descripción:** Un portal SaaS/B2B donde las empresas introducen su idea de negocio y, mediante un wizard guiado por IA, definen los requisitos. El sistema orquesta automáticamente la generación del código y el despliegue, entregando el MVP en 48-72 horas.

**Características Clave:**
1. **AI Scoping Wizard:** Un chatbot que transforma la idea del cliente en un "Mega-Prompt" estructurado para Bolt.new o Lovable.
2. **Pipeline de Despliegue Automatizado (n8n):** Conecta la pasarela de pago con la creación de repositorios, bases de datos (Supabase) y dominios.
3. **Dashboard de "Vibe Tracking":** El cliente ve en tiempo real cómo su MVP cobra vida (integración con webhooks de los entornos de IA).

**Modelo de Precios (Tiered Pricing):**
*   **Tier 1: "Landing & Lead" (48h):** Landing page de alta conversión + CRM básico + automatización de emails (n8n). Precio: $1,500.
*   **Tier 2: "SaaS MVP" (72h):** App web completa (Frontend + Backend + DB) con autenticación y pagos (Stripe). Precio: $4,500.
*   **Tier 3: "Internal Tool" (48h):** Dashboard administrativo o panel de operaciones conectado a sus APIs existentes. Precio: $2,500.

### 2. Extracción de Código: El Motor de Orquestación

Dado que la agencia utiliza herramientas de "Vibe Coding" (Bolt.new, Lovable) y automatización (n8n), el "código" central de esta agencia no es el frontend del MVP, sino el **Backend de Orquestación** que recibe el pedido del cliente, genera los prompts maestros para las IAs y dispara los flujos de n8n.

A continuación, se extrae el código en **Node.js/TypeScript** del endpoint principal que inicia la "Forja" del MVP.

```typescript
// ==========================================================
// ZERO-DAY LAUNCHPAD - MOTOR DE ORQUESTACIÓN DE MVPs
// Archivo: src/controllers/mvpForge.controller.ts
// ==========================================================

import { Request, Response } from 'express';
import { n8nWebhookClient } from '../services/n8n.service';
import { promptEngineer } from '../services/aiPrompt.service';
import { githubService } from '../services/github.service';

interface MVPRequest {
  clientName: string;
  businessIdea: string;
  targetAudience: string;
  tier: 'landing' | 'saas' | 'internal_tool';
  specificFeatures: string[];
}

export const forgeMVP = async (req: Request, res: Response) => {
  try {
    const payload: MVPRequest = req.body;

    // 1. Validación y Preparación del Entorno
    console.log(`[Zero-Day] Iniciando forja de MVP para ${payload.clientName} en ${payload.tier}`);
    
    // 2. Generación del "Mega-Prompt" para Bolt.new / Lovable
    // La IA traduce la idea de negocio en instrucciones técnicas precisas para el entorno de Vibe Coding
    const masterPrompt = await promptEngineer.generateVibeCodingPrompt({
      idea: payload.businessIdea,
      audience: payload.targetAudience,
      stack: payload.tier === 'saas' ? 'React, Tailwind, Supabase, Stripe' : 'Next.js, Tailwind',
      features: payload.specificFeatures
    });

    // 3. Creación de Infraestructura Base (Automatizado)
    const repoName = `zeroday-${payload.clientName.toLowerCase().replace(/\s+/g, '-')}-${Date.now()}`;
    const repo = await githubService.createPrivateRepo(repoName);
    
    // Inicializar DB si es Tier SaaS
    let supabaseUrl = '';
    if (payload.tier === 'saas') {
      supabaseUrl = await n8nWebhookClient.triggerWorkflow('create_supabase_project', { repoName });
    }

    // 4. Disparar el Flujo de n8n para inyectar el código en Bolt.new / Lovable
    // n8n actúa como el puente entre nuestra API y los entornos de Vibe Coding
    const vibeCodingSession = await n8nWebhookClient.triggerWorkflow('init_vibe_coding_session', {
      prompt: masterPrompt,
      repoUrl: repo.clone_url,
      environment: payload.tier === 'saas' ? 'Lovable' : 'Bolt.new',
      supabaseCredentials: supabaseUrl ? { url: supabaseUrl, apiKey: '***' } : null
    });

    // 5. Respuesta al Cliente / Dashboard
    res.status(202).json({
      success: true,
      message: '¡Tu MVP está en la forja! Tiempo estimado: 48-72 horas.',
      trackingData: {
        projectId: repo.id,
        vibeSessionId: vibeCodingSession.sessionId,
        estimatedDelivery: new Date(Date.now() + 72 * 60 * 60 * 1000).toISOString(),
        status: 'GENERATING_CODE_VIA_AI',
        dashboardUrl: `https://launchpad.zeroday.agency/track/${repo.id}`
      }
    });

  } catch (error) {
    console.error('[Zero-Day Error]', error);
    res.status(500).json({ error: 'Fallo en la orquestación de la forja de MVP.' });
  }
};
```

#### Flujo de Trabajo (Lo que hace el código en la práctica):

1. **Input:** El cliente rellena el formulario en *Zero-Day Launchpad* y paga.
2. **Prompt Engineering (`promptEngineer`):** El sistema toma la idea de negocio y la convierte en un prompt ultra-detallado (arquitectura, esquema de base de datos, diseño UI/UX, rutas) optimizado para que **Lovable** o **Bolt.new** no alucinen y generen código limpio a la primera.
3. **Infraestructura (`githubService` & `n8n`):** Se crea el repo en GitHub. Si es un SaaS, n8n crea automáticamente un proyecto en Supabase (Base de datos).
4. **Vibe Coding (`n8nWebhookClient`):** n8n abre una sesión en el entorno de IA, inyecta el "Mega-Prompt" y comienza a generar el frontend y backend.
5. **Output:** El cliente recibe un link a su dashboard donde puede ver el progreso en tiempo real. En 72 horas, el código está desplegado en Vercel/Netlify automáticamente.

**Por qué esto maximiza el margen:**
El código de orquestación elimina la necesidad de tener un Project Manager o un DevOps humano configurando repos, bases de datos y entornos. El 90% del trabajo técnico lo hace la IA (Bolt/Lovable) y el 10% restante lo hace este script de Node.js y n8n, permitiendo que un equipo de 2-3 personas facture como una agencia de 20.

```typescript
import OpenAI from "openai";

const openai = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });

export async function generateMasterPrompt(idea: string, tier: string, features: string[]) {
  const systemPrompt = `
    Eres un Arquitecto de Software Senior y Experto en "Vibe Coding" (Bolt.new / Lovable).
    Tu tarea es generar un "Mega-Prompt" técnico y exhaustivo para que una IA generadora de código construya un MVP.
    El prompt debe incluir:
    1. Estructura de carpetas y arquitectura.
    2. Esquema de base de datos (Prisma/Supabase).
    3. Componentes de UI (Tailwind, shadcn/ui) y diseño "Vibe" (moderno, oscuro, glassmorphism).
    4. Lógica de backend y endpoints.
    5. Instrucciones estrictas para evitar alucinaciones y usar solo librerías estándar.
  `;

  const userPrompt = `
    Idea de Negocio: ${idea}
    Tier del MVP: ${tier}
    Features Clave: ${features.join(', ')}
    
    Genera el Mega-Prompt completo en formato Markdown.
  `;

  const response = await openai.chat.completions.create({
    model: "gpt-4o",
    messages: [
      { role: "system", content: systemPrompt },
      { role: "user", content: userPrompt }
    ],
  });

  return response.choices[0].message.content;
}
```

```typescript
import { generateMasterPrompt } from "./ai-forge";
import { prisma } from "./prisma";

// Simulación de servicios externos (GitHub, n8n)
async function createGithubRepo(name: string) {
  // Llamada real a la API de GitHub
  return { clone_url: `https://github.com/zeroday-agency/${name}.git`, id: name };
}

async function triggerN8nWorkflow(masterPrompt: string, repoUrl: string, tier: string) {
  // Llamada real al Webhook de n8n
  const res = await fetch(process.env.N8N_WEBHOOK_URL!, {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ prompt: masterPrompt, repo: repoUrl, env: tier === 'saas' ? 'Lovable' : 'Bolt' })
  });
  const data = await res.json();
  return data.sessionId;
}

export async function forgeProject(projectId: string) {
  const project = await prisma.project.findUnique({ where: { id: projectId } });
  if (!project) throw new Error("Proyecto no encontrado");

  // 1. Actualizar estado
  await prisma.project.update({
    where: { id: projectId },
    data: { status: "FORGING" }
  });

  // 2. Generar Prompt Maestro
  const features = ["Autenticación", "Dashboard", "Pagos"]; // Extraer de DB en prod
  const masterPrompt = await generateMasterPrompt(project.businessIdea, project.tier, features);

  // 3. Crear Repo
  const repo = await createGithubRepo(`zeroday-${project.id}`);

  // 4. Disparar n8n
  const sessionId = await triggerN8nWorkflow(masterPrompt, repo.clone_url, project.tier);

  // 5. Guardar en DB
  await prisma.project.update({
    where: { id: projectId },
    data: { repoUrl: repo.clone_url, n8nSessionId: sessionId }
  });

  return { repoUrl: repo.clone_url, sessionId };
}
```

```typescript
import { NextRequest, NextResponse } from "next/server";
import { prisma } from "@/lib/services/prisma";

export async function POST(req: NextRequest) {
  const body = await req.json();
  const { sessionId, status, milestone, logs, liveUrl } = body;

  // Buscar proyecto por el ID de sesión de n8n
  const project = await prisma.project.findFirst({
    where: { n8nSessionId: sessionId }
  });

  if (!project) return NextResponse.json({ error: "Not found" }, { status: 404 });

  // Actualizar proyecto
  await prisma.project.update({
    where: { id: project.id },
    data: {
      status: status === 'DONE' ? 'COMPLETED' : 'FORGING',
      liveUrl: liveUrl || project.liveUrl,
      milestones: {
        upsert: {
          where: { title: milestone },
          update: { status: 'DONE', logs },
          create: { title: milestone, status: 'DONE', logs }
        }
      }
    }
  });

  return NextResponse.json({ success: true });
}
```
