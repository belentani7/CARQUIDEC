## I. DEFINICIÓN FUNDACIONAL DE MARCA

### Qué es CIRCUIT

CIRCUIT es una consultora operativa de modernización de flujos de trabajo. No es una agencia de software, no es un integrador tecnológico, no es una consultora de transformación digital genérica. Es un estudio de ingeniería de procesos que diagnostica, rediseña e implementa la forma en que una empresa funciona por dentro.

**Posicionamiento exacto:**

CIRCUIT ocupa el espacio entre la consultoría estratégica (que dice qué hacer) y la implementación técnica (que instala herramientas). CIRCUIT hace ambas cosas, pero desde el proceso, no desde la tecnología.

**Propuesta de valor en una frase:**

> Identificamos dónde tu empresa pierde tiempo, información y dinero entre tareas, y rediseñamos el circuito para que funcione sin fricción.

**Propósito funcional:**

Eliminar la distancia entre cómo una empresa trabaja hoy y cómo debería trabajar para ser eficiente, escalable y sostenible.

**Propósito emocional:**

Devolver a las personas el control sobre su jornada laboral. Que dejen de sentir que el trabajo les gestiona a ellas.

---

### Lo que CIRCUIT NO es (anti-posicionamiento)

Esto es tan importante como lo que sí es. CIRCUIT se define también por lo que rechaza:

- No vende inteligencia artificial como solución universal.
- No automatiza por automatizar.
- No impone herramientas.
- No hace "transformación digital" como eslogan vacío.
- No sustituye personas por tecnología.
- No vende humo estratégico sin implementación.
- No empieza por el software. Empieza por la pregunta.

Este anti-posicionamiento es el principal diferenciador competitivo. En un mercado saturado de agencias que venden "IA para empresas" y "automatización total", CIRCUIT se posiciona como el adulto en la sala: primero entiende, luego decide si hace falta tecnología, y solo entonces implementa.

## II. IDENTIDAD VISUAL

### Dirección de arte y concepto visual

La identidad visual de CIRCUIT debe transmitir tres cosas simultáneamente: **claridad estructural**, **precisión técnica** y **calidez humana**. No puede parecer fría como una consultora tecnológica genérica, ni caótica como una agencia creativa. Debe sentirse como un plano de ingeniero bien dibujado: cada línea tiene un propósito.

**Concepto visual central: el diagrama de flujo como lenguaje.**

Toda la identidad gira en torno a la representación visual de circuitos, flujos, nodos, conexiones y rutas. No como decoración tecnológica genérica, sino como metáfora del trabajo real de la empresa: entender cómo va la información de un punto a otro y eliminar lo que sobra en el camino.

---

### Logotipo

**Opción principal recomendada:**

Wordmark tipográfico: **CIRCUIT** en mayúsculas, tipografía geométrica sans-serif de peso medio (tipo Space Grotesk, General Sans o Söhne). La letra **U** se sustituye por un símbolo de nodo/conexión: un pequeño cuadrado o círculo con una línea que entra y otra que sale, sugiriendo un punto de paso dentro del circuito.

El nodo en la U comunica: aquí hay una decisión, un punto de conexión, algo que pasa por un filtro antes de continuar. Es el concepto entero en un glifo.

**Variante compacta (para favicon, app, redes):**

Solo el nodo: ◉ con dos líneas (entrada y salida) horizontales. Funciona como símbolo independiente.

**Versión extendida (para documentos, web, presentaciones):**

Modernización de operaciones y circuitos de trabajo

**Fondo web principal:** Negro `#0D0D0D` con texto blanco. Secciones alternando con fondo `#F5F3EF` para bloques de lectura extensa. El ámbar se reserva para elementos interactivos y momentos clave.

### Sistema gráfico: el lenguaje de circuitos

Este es el elemento visual más diferenciador. CIRCUIT debe desarrollar un **sistema propio de diagramas y representaciones visuales** que se use en toda la comunicación:

**Elementos del sistema:**

- **Nodos:** Círculos o cuadrados pequeños que representan puntos del proceso (una persona, una herramienta, una decisión, un documento).
- **Líneas de flujo:** Líneas rectas o con ángulos de 90° (nunca curvas orgánicas) que conectan nodos. Representan el camino de la información o la tarea.
- **Zonas de fricción:** Áreas marcadas en ámbar o rojo dentro del diagrama donde se detecta un problema.
- **Zonas resueltas:** Las mismas áreas en verde cuando se muestra el "después".
- **Etiquetas:** Texto monoespaciado junto a cada nodo indicando qué es: `PERSONA`, `SISTEMA`, `DECISIÓN`, `DOCUMENTO`, `ESPERA`.

**Aplicación:**

Estos diagramas se usan en:
- La web (secciones de método, casos de uso).
- Propuestas comerciales.
- Informes de diagnóstico.
- Redes sociales (contenido educativo).
- Presentaciones.
- Merchandising (si aplica).

**Estilo de ilustración:**

Línea fina, geométrica, sobre fondo oscuro o claro. Sin rellenos excesivos. Inspiración: diagramas de ingeniería, esquemas eléctricos, blueprints. Nada de ilustraciones 3D genéricas ni mockups de ordenadores flotando.

## III. ESTRATEGIA DE NEGOCIO

### Modelo de servicios

CIRCUIT opera con dos líneas de servicio claramente diferenciadas por tamaño de cliente y profundidad de intervención.

---

#### Línea 1: CIRCUIT ESSENTIAL

**Cliente objetivo:** Autónomos, freelancers, microempresas y pequeñas empresas (1-15 personas). Negocios locales, profesionales independientes, pequeños despachos, tiendas online pequeñas, consultores individuales.

**Problema que resuelve:** "Sé que pierdo tiempo en algo, pero no sé exactamente dónde ni cómo arreglarlo."

**Servicio principal: Diagnóstico de Circuito**

Entregable concreto y acotado. No es una consultoría abierta. Es un análisis con inicio, fin y entregables definidos.

**Proceso:**

1. Sesión inicial de descubrimiento (60-90 min, videollamada o presencial).
2. Solicitud de acceso a herramientas, documentos y flujos relevantes.
3. Análisis del proceso seleccionado por el cliente.
4. Entrega del informe.

**Entregables del diagnóstico:**

- Mapa visual del proceso actual (diagrama de circuito).
- Identificación de zonas de fricción (clasificadas: repetición, desconexión, espera, error, dependencia, coste).
- Oportunidades de mejora priorizadas por impacto y facilidad de implementación.
- Propuesta de circuito optimizado (diagrama del "después").
- Recomendaciones concretas de implementación (herramientas, automatizaciones, cambios de procedimiento).
- Estimación de coste y plazo si el cliente quiere que CIRCUIT implemente.

**Precio base:** Desde 80 € (diagnóstico de un proceso simple).

**Escalado dentro de Essential:**

Si tras el diagnóstico el cliente quiere implementación, se presupuesta aparte según alcance. CIRCUIT no obliga a contratar la implementación. El diagnóstico tiene valor en sí mismo.

**Ejemplos de procesos diagnosticables:**

- Gestión de clientes desde primer contacto hasta entrega.
- Proceso de presupuestación y seguimiento comercial.
- Gestión de reservas o citas.
- Flujo documental (facturas, contratos, informes).
- Atención al cliente y gestión de incidencias.
- Comunicación interna en equipos pequeños.
- Generación de informes o reportes periódicos.
- Gestión de contenidos y publicación.
- Onboarding de nuevos clientes o empleados.

---

**Cliente objetivo:** Empresas medianas y grandes (15+ personas), organizaciones con múltiples departamentos, empresas con operaciones complejas, compañías en crecimiento que han acumulado herramientas y procesos sin orden.

**Problema que resuelve:** "El problema no es una tarea concreta. Es que personas, departamentos y sistemas no se coordinan bien y eso nos cuesta dinero, tiempo y errores."

**Servicio: Proyecto de Operational Modernization**

Proyecto completo con fases definidas. Duración típica: 6 semanas a 6 meses según complejidad.

## I. CONCEPTO VISUAL: AGUA NEGRA

La web no tiene fondo: tiene **superficie**. Un plano de agua negra, casi inmóvil, que reacciona al paso del usuario. La luz no es decoración: es **información**. Cuando algo importa, se ilumina en ámbar. Cuando algo se resuelve, respira en verde. El resto permanece en oscuridad precisa.

**Principios visuales:**

| Principio | Aplicación |
|---|---|
| **Oscuridad como lienzo** | Fondo `#0A0A0B`–`#0D0D0D` permanente. Sin secciones blancas. El contraste lo da la luz, no el color. |
| **Luz líquida** | Un shader WebGL de agua negra con reflejos ámbar que fluye lento detrás del contenido. Reacciona al cursor (ondas) y a la velocidad de scroll (corriente). |
| **Tipografía monumental** | Títulos gigantes, blancos, geométricos. El texto es el elemento visual principal. |
| **La línea como narrativa** | Una línea fina ámbar con nodos recorre toda la web: es el circuito. Se dibuja, se enciende, progresa con el scroll. |
| **Grano vivo** | Overlay de grain sutil (3-4% opacidad) que da textura de materia, no de pantalla. |
| **Cero ornamentación** | Sin bordes gruesos, sin tarjetas con sombra, sin gradientes de color. Solo luz, línea y tipo. |

## II. WEB CONSCIENTE

La web de CIRCUIT se comporta como un sistema consciente. Tres verbos la definen:

### 1. PERCIBE

- **Posición del cursor** → el agua genera ondas suaves a su paso.
- **Velocidad de scroll** → la corriente del agua acelera o se calma.
- **Sección activa** → el nodo correspondiente del circuito (nav) se enciende. La web sabe dónde estás.
- **Inactividad** → si el usuario se detiene 10 segundos, la web "respira": el agua late lento, nada parpadea, nada exige.
- **Contexto técnico** → detecta `prefers-reduced-motion`, `save-data`, puntero táctil, FPS reales y visibilidad de pestaña.

### 2. RESPONDE

- El texto se **ilumina palabra a palabra** con el scroll (no aparece: despierta).
- El circuito del método **se rediseña delante del usuario**: el diagrama caótico se desdibuja y el optimizado se dibuja en su lugar.
- Los botones son **magnéticos**: se acercan ligeramente al cursor.
- El cursor es un **instrumento**: punto + anillo que cambia de estado según lo que toca.

### 3. RESPETA

- `prefers-reduced-motion` → toda animación se desactiva; el contenido queda visible y estático. Sin excepciones.
- `save-data` o FPS bajos → el shader se apaga y queda un fondo estático de agua negra pre-renderizado.
- Pestaña oculta → todo se pausa (cero consumo en segundo plano).
- Sin dark patterns, sin popups agresivos, sin cookies de rastreo. Fuentes autoalojadas. Analytics de privacidad (Plausible).
- La web nunca grita. Si el usuario no hace nada, la web casi no hace nada.

## VI. EL AGUA: SHADER DE LUZ LÍQUIDA

Un único plano WebGL a pantalla completa, fijo detrás de todo (`position: fixed; z-index: -1`). FBM con domain-warping para el aspecto líquido, base casi negra, specular ámbar, onda que sigue al cursor y corriente que sigue al scroll.

```js
// motion/liquid.js
import * as THREE from 'three'

const FRAG = /* glsl */ `
  precision highp float;
  uniform float uTime; uniform vec2 uRes;
  uniform vec2 uMouse; uniform float uVel;

  float hash(vec2 p){ return fract(sin(dot(p, vec2(127.1,311.7)))*43758.5453); }
  float noise(vec2 p){
    vec2 i=floor(p), f=fract(p); vec2 u=f*f*(3.-2.*f);
    return mix(mix(hash(i),hash(i+vec2(1,0)),u.x),
               mix(hash(i+vec2(0,1)),hash(i+vec2(1,1)),u.x),u.y);
  }
  float fbm(vec2 p){
    float v=0., a=.5;
    for(int i=0;i<5;i++){ v+=a*noise(p); p*=2.03; a*=.5; }
    return v;
  }
  void main(){
    vec2 uv = gl_FragCoord.xy / uRes;
    vec2 p = uv * vec2(uRes.x/uRes.y, 1.) * 2.6;
    float t = uTime * .05 + uVel;

    vec2 q = vec2(fbm(p + t), fbm(p - t*.7));
    vec2 r = vec2(fbm(p + 2.5*q + vec2(1.7,9.2) + .12*t),
                  fbm(p + 2.5*q + vec2(8.3,2.8) - .10*t));
    float f = fbm(p + 2.2*r);

    // agua negra
    vec3 col = mix(vec3(.012,.012,.014), vec3(.05,.05,.06), f*f);

    // luz líquida ámbar: solo en crestas
    vec3 ambar = vec3(.91,.66,.22);
    col += ambar * pow(f, 4.) * .38;

    // onda del cursor
    float d = distance(uv, uMouse);
    col += ambar * smoothstep(.22, 0., d) * .06;

    // viñeta
    col *= smoothstep(1.25, .35, length(uv - .5));
    gl_FragColor = vec4(col, 1.);
  }
`

export function initLiquid() {
  if (consciente.reduced || consciente.saveData) return null

  const canvas = document.querySelector('#liquid')
  const renderer = new THREE.WebGLRenderer({ canvas, antialias: false })
  const scene = new THREE.Scene()
  const cam = new THREE.OrthographicCamera(-1, 1, 1, -1, 0, 1)
  const uniforms = {
    uTime: { value: 0 }, uRes: { value: new THREE.Vector2() },
    uMouse: { value: new THREE.Vector2(.5, .5) }, uVel: { value: 0 },
  }
  scene.add(new THREE.Mesh(
    new THREE.PlaneGeometry(2, 2),
    new THREE.ShaderMaterial({ fragmentShader: FRAG, uniforms,
      vertexShader: 'void main(){ gl_Position = vec4(position,1.); }' })
  ))

  const resize = () => {
    const dpr = Math.min(devicePixelRatio, 1.5) // presupuesto: nunca >1.5
    renderer.setPixelRatio(dpr)
    renderer.setSize(innerWidth, innerHeight)
    uniforms.uRes.value.set(innerWidth * dpr, innerHeight * dpr)
  }
  resize(); addEventListener('resize', resize)

  // percepción: cursor y velocidad de scroll
  addEventListener('pointermove', e =>
    uniforms.uMouse.value.set(e.clientX / innerWidth, 1 - e.clientY / innerHeight))

  let vel = 0
  ScrollTrigger.create({
    onUpdate: self => { vel = Math.min(Math.abs(self.getVelocity()) / 3000, 1) }
  })

  // respeto: pausa si la pestaña no se ve
  let visible = true
  document.addEventListener('visibilitychange', () =>
    (visible = document.visibilityState === 'visible'))

  renderer.setAnimationLoop(now => {
    if (!visible) return
    uniforms.uTime.value = now / 1000
    uniforms.uVel.value += (vel - uniforms.uVel.value) * .04
    vel *= .96
    renderer.render(scene, cam)
  })

  return renderer
}
```

**Fallback estático:** si el shader no se monta (reduced / save-data / FPS bajos), el canvas se sustituye por la imagen pre-renderizada del agua negra — exactamente la estética de la pieza visual generada — sin costo de runtime.

const GLYPHS = '█▓▒░/\\<>—·01'
export function scramble(el, final, dur = 700) {
  if (consciente.reduced) { el.textContent = final; return }
  const start = performance.now()
  ;(function tick(now) {
    const p = Math.min((now - start) / dur, 1)
    el.textContent = [...final].map((c, i) =>
      i < p * final.length ? c : GLYPHS[Math.random() * GLYPHS.length | 0]).join('')
    if (p < 1) requestAnimationFrame(tick)
  })(start)
}

## IX. GOBERNADOR DE RENDIMIENTO (la web se autorregula)

La web mide sus propios FPS. Si el dispositivo sufre, **degrada con elegancia**: primero apaga el shader, luego el cursor custom, luego el smooth scroll. Nunca jank.

```js
// motion/governor.js
export function initGovernor(liquid) {
  let frames = 0, last = performance.now(), strikes = 0
  gsap.ticker.add(() => {
    frames++
    const now = performance.now()
    if (now - last >= 2000) {
      const fps = frames / ((now - last) / 1000)
      if (fps < 28 && ++strikes >= 2 && liquid) {
        liquid.setAnimationLoop(null)          // apaga el agua
        liquid.dispose()
        document.body.classList.add('agua-estatica') // fallback imagen
      }
      frames = 0; last = now
    }
  })
}
```

# III. EL MOTOR DE AGUA NEGRA (THREE.JS SHADER)

Este componente se renderiza fijo en el fondo (`z-index: -1`). Utiliza un solo plano y un Fragment Shader para generar el FBM (Fractional Brownian Motion) que simula el líquido viscoso.

### `src/components/canvas/LiquidWater.tsx`
```tsx
"use client";
import { useEffect, useRef } from 'react';
import * as THREE from 'three';

const vertexShader = `
  void main() {
    gl_Position = vec4(position, 1.0);
  }
`;

const fragmentShader = `
  precision highp float;
  uniform float uTime;
  uniform vec2 uResolution;
  uniform vec2 uMouse;
  uniform float uVelocity;

  // Hash y Noise para FBM
  float hash(vec2 p) { return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453); }
  float noise(vec2 p) {
    vec2 i = floor(p); vec2 f = fract(p); vec2 u = f * f * (3.0 - 2.0 * f);
    return mix(mix(hash(i), hash(i + vec2(1.0, 0.0)), u.x),
               mix(hash(i + vec2(0.0, 1.0)), hash(i + vec2(1.0, 1.0)), u.x), u.y);
  }
  float fbm(vec2 p) {
    float v = 0.0; float a = 0.5;
    for (int i = 0; i < 5; i++) { v += a * noise(p); p *= 2.03; a *= 0.5; }
    return v;
  }

  void main() {
    vec2 uv = gl_FragCoord.xy / uResolution;
    vec2 p = uv * vec2(uResolution.x / uResolution.y, 1.0) * 2.5;
    float t = uTime * 0.04 + uVelocity;

    // Domain Warping para efecto líquido
    vec2 q = vec2(fbm(p + t), fbm(p - t * 0.7));
    vec2 r = vec2(fbm(p + 2.5 * q + vec2(1.7, 9.2) + 0.12 * t),
                  fbm(p + 2.5 * q + vec2(8.3, 2.8) - 0.10 * t));
    float f = fbm(p + 2.2 * r);

    // Color Base: Negro Abismo
    vec3 col = mix(vec3(0.012, 0.012, 0.014), vec3(0.05, 0.05, 0.06), f * f);

    // Luz Líquida: Ámbar Señal en las crestas
    vec3 ambar = vec3(0.91, 0.66, 0.22);
    col += ambar * pow(f, 6.0) * 0.45;

    // Interacción: Onda suave del cursor
    float d = distance(uv, uMouse);
    col += ambar * smoothstep(0.25, 0.0, d) * 0.08;

    // Viñeta profunda
    col *= smoothstep(1.3, 0.4, length(uv - 0.5));
    
    gl_FragColor = vec4(col, 1.0);
  }
`;

export default function LiquidWater() {
  const canvasRef = useRef<HTMLCanvasElement>(null);
  const mouseRef = useRef({ x: 0.5, y: 0.5 });
  const velRef = useRef(0);

  useEffect(() => {
    if (!canvasRef.current) return;

    const renderer = new THREE.WebGLRenderer({ canvas: canvasRef.current, antialias: false });
    const scene = new THREE.Scene();
    const camera = new THREE.OrthographicCamera(-1, 1, 1, -1, 0, 1);
    
    const uniforms = {
      uTime: { value: 0 },
      uResolution: { value: new THREE.Vector2(window.innerWidth, window.innerHeight) },
      uMouse: { value: new THREE.Vector2(0.5, 0.5) },
      uVelocity: { value: 0 }
    };

    const mesh = new THREE.Mesh(
      new THREE.PlaneGeometry(2, 2),
      new THREE.ShaderMaterial({ vertexShader, fragmentShader, uniforms })
    );
    scene.add(mesh);

    const resize = () => {
      const dpr = Math.min(window.devicePixelRatio, 1.5); // Cap DPR for performance
      renderer.setPixelRatio(dpr);
      renderer.setSize(window.innerWidth, window.innerHeight);
      uniforms.uResolution.value.set(window.innerWidth * dpr, window.innerHeight * dpr);
    };
    resize();
    window.addEventListener('resize', resize);

    // Tracking
    const onMove = (e: MouseEvent) => {
      mouseRef.current.x = e.clientX / window.innerWidth;
      mouseRef.current.y = 1.0 - (e.clientY / window.innerHeight);
    };
    window.addEventListener('mousemove', onMove);

    let scrollY = 0;
    const onScroll = () => {
      const newY = window.scrollY;
      velRef.current = Math.min(Math.abs(newY - scrollY) / 100, 1.0);
      scrollY = newY;
    };
    window.addEventListener('scroll', onScroll, { passive: true });

    let frameId: number;
    let lastTime = performance.now();
    
    const animate = (time: number) => {
      const dt = (time - lastTime) / 1000;
      lastTime = time;
      
      uniforms.uTime.value += dt;
      uniforms.uMouse.value.lerp(new THREE.Vector2(mouseRef.current.x, mouseRef.current.y), 0.05);
      uniforms.uVelocity.value += (velRef.current - uniforms.uVelocity.value) * 0.05;
      velRef.current *= 0.95; // Decay velocity

      renderer.render(scene, camera);
      frameId = requestAnimationFrame(animate);
    };
    frameId = requestAnimationFrame(animate);

    return () => {
      cancelAnimationFrame(frameId);
      window.removeEventListener('resize', resize);
      window.removeEventListener('mousemove', onMove);
      window.removeEventListener('scroll', onScroll);
      renderer.dispose();
    };
  }, []);

  return <canvas ref={canvasRef} className="fixed inset-0 w-full h-full -z-10" />;
}
```

### 2. El Método (Scroll Horizontal Pinned)

import { gsap, ScrollTrigger } from '@/lib/motion-config';

const phases = [
  { num: '01', title: 'Mapear', desc: 'Observamos y representamos cómo funciona el circuito.' },
  { num: '02', title: 'Detectar', desc: 'Buscamos las zonas donde el circuito pierde eficiencia.' },
  { num: '03', title: 'Rediseñar', desc: 'Decidimos qué eliminar, simplificar o automatizar.' },
  { num: '04', title: 'Implementar', desc: 'Construimos el nuevo circuito sin fricción.' },
  { num: '05', title: 'Medir', desc: 'Demostramos que funciona con datos reales.' },
];

export default function Method() {
  const containerRef = useRef<HTMLDivElement>(null);
  const panelsRef = useRef<HTMLDivElement>(null);

  useLayoutEffect(() => {
    const ctx = gsap.context(() => {
      const panels = gsap.utils.toArray<HTMLElement>('.panel');
      
      gsap.to(panels, {
        xPercent: -100 * (panels.length - 1),
        ease: 'none',

          trigger: containerRef.current,
          pin: true,
          scrub: 1,
          end: () => '+=' + (window.innerWidth * (panels.length - 1) * 0.8),

# VI. INTEGRACIÓN DE LENIS (SMOOTH SCROLL)

Para que GSAP ScrollTrigger funcione con inercia de alta gama sin romper el scroll nativo del navegador.

### `src/components/motion/SmoothScroll.tsx`
```tsx
"use client";
import { ReactNode, useEffect, useRef } from 'react';
import Lenis from 'lenis';
import { gsap, ScrollTrigger } from '@/lib/motion-config';

export default function SmoothScroll({ children }: { children: ReactNode }) {
  const lenisRef = useRef<Lenis | null>(null);

  useEffect(() => {
    // Respeto por reduced-motion
    if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) return;

    const lenis = new Lenis({
      duration: 1.2,
      easing: (t: number) => Math.min(1, 1.001 - Math.pow(2, -10 * t)),
      orientation: 'vertical',
      gestureOrientation: 'vertical',
      smoothWheel: true,
    });
    lenisRef.current = lenis;

    lenis.on('scroll', ScrollTrigger.update);

    gsap.ticker.add((time) => {
      lenis.raf(time * 1000);
    });
    gsap.ticker.lagSmoothing(0);

    return () => {
      lenis.destroy();
      gsap.ticker.remove(lenis.raf);
    };
  }, []);

  return <>{children}</>;
}
```
*Nota: Envuelve el `{children}` dentro de `src/app/layout.tsx` con este componente `<SmoothScroll>`.*

# VII. GOBERNADOR DE RENDIMIENTO (EL TOQUE FINAL)

La web debe ser premium, pero no puede quemar la batería de un portátil ni colapsar un móvil de gama baja. Añade este hook en tu `layout.tsx` o en un componente global `PerformanceGovernor`.

```typescript
"use client";
import { useEffect } from 'react';

export function usePerformanceGovernor() {
  useEffect(() => {
    let frames = 0;
    let lastTime = performance.now();
    let strikes = 0;

    const tick = () => {
      frames++;
      const now = performance.now();
      if (now - lastTime >= 2000) {
        const fps = frames / ((now - lastTime) / 1000);
        
        // Si los FPS caen por debajo de 30 durante 2 ciclos seguidos
        if (fps < 30) {
          strikes++;
          if (strikes >= 2) {
            // DEGRADACIÓN ELEGANTE:
            // 1. Desactivar animaciones de fondo complejas
            document.body.classList.add('performance-degraded');
            // 2. El CSS ocultará el canvas WebGL y mostrará un gradiente estático
          }
        } else {
          strikes = 0;
        }
        
        frames = 0;
        lastTime = now;
      }
      requestAnimationFrame(tick);
    };
    
    requestAnimationFrame(tick);
  }, []);
}
```

const GLYPHS = '█▓▒░<>/\\—·01';

export function scramble(el: HTMLElement, final: string, dur = 800) {
  if (typeof window === 'undefined') return;
  if (window.matchMedia('(prefers-reduced-motion: reduce)').matches) {
    el.textContent = final;
    return;
  }
  const start = performance.now();
  const tick = (now: number) => {
    const p = Math.min((now - start) / dur, 1);
    el.textContent = [...final]
      .map((c, i) => (i < p * final.length ? c : GLYPHS[(Math.random() * GLYPHS.length) | 0]))
      .join('');
    if (p < 1) requestAnimationFrame(tick);
  };
  requestAnimationFrame(tick);
}

'use client';
import { useEffect } from 'react';

export default function Conscious() {
  useEffect(() => {
    const reduced = window.matchMedia('(prefers-reduced-motion: reduce)').matches;
    const saveData = !!(navigator as unknown as { connection?: { saveData?: boolean } }).connection?.saveData;

    if (reduced) document.documentElement.classList.add('is-static');
    if (saveData) document.documentElement.classList.add('performance-degraded');

    if (reduced) return;

    // Gobernador de FPS: degrada con elegancia si el dispositivo sufre
    let frames = 0, last = performance.now(), strikes = 0, raf = 0;
    const tick = () => {
      frames++;
      const now = performance.now();
      if (now - last >= 2000) {
        const fps = frames / ((now - last) / 1000);
        if (fps < 28) {
          if (++strikes >= 2) document.documentElement.classList.add('performance-degraded');
        } else strikes = 0;
        frames = 0; last = now;
      }
      raf = requestAnimationFrame(tick);
    };
    raf = requestAnimationFrame(tick);
    return () => cancelAnimationFrame(raf);
  }, []);
  return null;
}

import { ReactNode, useLayoutEffect, useRef } from 'react';
import { gsap, conscious } from '@/lib/motion-config';

export default function Magnetic({
  children, strength = 0.3, className = '',
}: { children: ReactNode; strength?: number; className?: string }) {
  const ref = useRef<HTMLDivElement>(null);

  useLayoutEffect(() => {
    if (conscious.coarse || conscious.reduced || !ref.current) return;
    const el = ref.current;
    const x = gsap.quickTo(el, 'x', { duration: 0.4, ease: 'power3' });
    const y = gsap.quickTo(el, 'y', { duration: 0.4, ease: 'power3' });

    const move = (e: PointerEvent) => {
      const r = el.getBoundingClientRect();
      x((e.clientX - r.left - r.width / 2) * strength);
      y((e.clientY - r.top - r.height / 2) * strength);
    };
    const reset = () => { x(0); y(0); };

    el.addEventListener('pointermove', move);
    el.addEventListener('pointerleave', reset);
    return () => {
      el.removeEventListener('pointermove', move);
      el.removeEventListener('pointerleave', reset);
    };
  }, [strength]);

  return <div ref={ref} className={`inline-block ${className}`}>{children}</div>;
}

'use client';
import { useLayoutEffect, useRef } from 'react';
import SplitType from 'split-type';
import { gsap, conscious } from '@/lib/motion-config';

export default function PageHeader({ kicker, title, desc }: { kicker: string; title: string; desc?: string }) {
  const ref = useRef<HTMLHeadingElement>(null);

  useLayoutEffect(() => {
    if (conscious.reduced || !ref.current) return;
    const split = new SplitType(ref.current, { types: 'chars' });
    const tl = gsap.timeline({ defaults: { ease: 'power4.out' } })
      .from('.ph-kicker', { yPercent: 140, autoAlpha: 0, duration: 0.7 })
      .from(split.chars!, { yPercent: 120, stagger: 0.03, duration: 0.9 }, '-=0.3')
      .from('.ph-desc', { y: 24, autoAlpha: 0, duration: 0.8 }, '-=0.4');
    return () => { tl.kill(); split.revert(); };
  }, [title]);

  return (
    <header className="mb-20 pt-16">
      <p className="ph-kicker line-mask font-mono text-[11px] tracking-[0.35em] text-neblina uppercase mb-6">
        <span>{kicker}</span>
      </p>
      <h1 ref={ref} className="font-display font-medium text-[clamp(2.8rem,8vw,7rem)] leading-none mb-6">
        {title}
      </h1>
      {desc && <p className="ph-desc text-neblina text-lg max-w-2xl leading-relaxed">{desc}</p>}
    </header>
  );
}

export default function PrincipiosPage() {
  const ref = useRef<HTMLDivElement>(null);
  const textRef = useRef<HTMLParagraphElement>(null);

  useLayoutEffect(() => {
    if (conscious.reduced || !textRef.current) return;
    const words = textRef.current.innerText.split(' ');

      .map((w) => `<span style="display:inline-block;margin-right:.28em;color:rgba(245,243,239,.14)">${w}</span>`)
