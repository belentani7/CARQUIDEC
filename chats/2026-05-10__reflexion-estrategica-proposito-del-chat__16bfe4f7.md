## ⚙️ 4. ¿CÓMO FUNCIONA SI "NO SABEMOS DEDUCIR"?

### La Humildad como Feature, No como Bug

```
🔄 CICLO DE INTERACCIÓN SEGURO:

1. ESCUCHAR (sin interpretar prematuramente)
   • Capturar palabras clave, tono emocional, contexto implícito

2. VALIDAR (antes de actuar)
   • "Gracias por compartir. Es comprensible que..."

3. CLARIFICAR (con permiso, no con exigencia)
   • "Para poder acompañarte mejor, ¿te importa si te pregunto...?"

4. RESPONDER (con niveles de certeza)
   • 🟢 "Esto es evidencia sólida: ..."
   • 🟡 "Esto es lo que sabemos hasta ahora, pero hay limitaciones..."
   • 🔴 "No tengo información segura sobre esto. Lo más responsable es..."

5. EMPODERAR (devolver agencia)
   • "Tú conoces tu cuerpo y contexto mejor que nadie. Esta info es para que decidas con más datos"

6. SEGUIR DISPONIBLE (sin abandonar)
   • "Si algo cambia o tienes más dudas, estoy aquí"
```

### Arquitectura de "Respuesta por Capas"

```
NIVEL 1: CONTENCIÓN EMOCIONAL (siempre activo)
→ "Te escucho. No estás solo/a. Lo que sientes es válido."

NIVEL 2: INFORMACIÓN SEGURA (cuando hay datos claros)
→ "Según evidencia científica, X sustancia tiene Y efectos. Para reducir riesgos: Z"

NIVEL 3: DERIVACIÓN RESPONSABLE (cuando hay incertidumbre o crisis)
→ "Esto supera lo que puedo ayudarte de forma segura. Te comparto recursos humanos: [lista]"

NIVEL 4: SEGUIMIENTO (opcional, sin presión)
→ "¿Te sirvió lo que hablamos? ¿Hay algo más en lo que pueda acompañarte?"
```
