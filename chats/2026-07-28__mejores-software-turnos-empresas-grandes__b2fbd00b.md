## 📐 CAPA 0 — MARCO LEGAL ADAPTATIVO (El cimiento innegociable)

Antes de cualquier software, el sistema debe respetar una jerarquía normativa que funciona como **restricciones duras** del motor de planificación:

### Jerarquía normativa aplicable

| Nivel | Norma | Restricción clave |
|---|---|---|
| **UE** | Directiva 2003/88/CE (Working Time Directive) | Máx. 48h/semana promedio (incluye horas extra), 11h descanso diario consecutivo, 24h descanso semanal + 11h diario = 35h mín., 4 semanas vacaciones mín., máx. 8h/día trabajo nocturno peligroso [[50]] |
| **UE** | Sentencia TJUE C-55/18 (CCOO vs Deutsche Bank, 2019) | Obligación de sistema **objetivo, fiable y accesible** de registro diario de jornada para TODOS los trabajadores [[51]] |
| **España** | Art. 34 Estatuto de los Trabajadores (RD-Leg 2/2015) | Máx. 40h/semana efectivo en cómputo anual; registro diario obligatorio con hora inicio/fin; 12h descanso entre jornadas (supera los 11h UE) [[90]][[91]] |
| **España** | RD-Ley 8/2019 | Registro de jornada obligatorio; sanciones graves: **751€ – 7.500€** por infracción [[34]] |
| **España** | Nueva ley control horario (vigencia 2026) | Registro **digital con trazabilidad y acceso remoto para Inspección de Trabajo** [[96]] |
| **España** | Art. 36 ET – Trabajo nocturno | Entre 22:00-06:00; máx. 8h/día promedio en 15 días; complemento de nocturnidad obligatorio [[89]] |
| **Convenio** | Convenio colectivo sectorial/empresa | Puede MEJORAR (nunca empeorar) lo anterior: bolsas de horas, multiplicadores festivos/nocturnos, ciclos de rotación, descansos adicionales [[16]] |

> **Principio adaptativo:** La Directiva es el *suelo*, no el techo. España exige 12h de descanso diario (vs. 11h UE) y 30 días naturales de vacaciones (vs. 20 días UE) [[50]]. Un software que solo cumple la Directiva **incumple en España**.

### Excepciones sectoriales críticas (derogaciones)

La Directiva permite derogaciones para **hospitales, seguridad, vigilancia, puertos, aeropuertos, medios, agricultura y turismo** cuando se requiere continuidad de servicio, siempre que se proporcione descanso compensatorio equivalente [[50]]. Esto afecta directamente a fábricas con producción continua, hospitales 24/7 y grandes superficies con horarios extendidos.

## 🔮 CAPA 5 — TENDENCIAS 2026: IA Y AUTOMATIZACIÓN EN WFM

El mercado está convergiendo hacia tres ejes [[25]][[30]][[28]]:

1. **IA predictiva integrada**: Para 2026, la IA se integra profundamente en el scheduling: análisis de datos históricos, previsión de absentismo, optimización automática de cobertura [[30]].
2. **Del scheduling al Strategic Workforce Planning**: Ya no basta con "cubrir turnos"; las herramientas evolucionan hacia planificación estratégica de plantilla, control de costes laborales y experiencia del empleado [[25]].
3. **Cumplimiento legal automatizado**: Con la nueva ley española de control horario digital (2026) y el endurecimiento de la inspección, el software debe generar registros con **trazabilidad completa y acceso remoto para Inspección de Trabajo** [[96]][[95]].

## ⚡ SÍNTESIS EJECUTIVA

> **No existe "el mejor software" universal.** Existe el software que resuelve tu combinación específica de: (a) complejidad de turnos, (b) marco convencional aplicable, (c) necesidad de hardware físico, (d) escala de plantilla, y (e) integración con tu ecosistema ERP/nómina existente.

Las tres decisiones que más impacto tienen:

1. **¿Necesitas hardware de acceso físico?** → Solo **Kelio** lo integra nativamente (tornos, biometría, RFID del Grupo Bodet) [[11]].
2. **¿Necesitas IA predictiva de demanda?** → **Plano WFM** (Optimizer) o **Workday** (ML forecasting) [[35]][[1]].
3. **¿Necesitas el motor de cálculo de turnos más potente al mejor precio?** → **aTurnos** (~1-3€/emp/mes con IA propia) o **PGPlanning** (motor exhaustivo para +100 empleados) [[45]][[35]].

        nonce = os.urandom(self._nonce_len); data = plaintext.encode()
        a = aad.encode() if aad else None
        if CRYPTO and self._aesgcm: ct = self._aesgcm.encrypt(nonce, data, a)
        else:
            ks = hashlib.sha256(self._master_key + nonce).digest()
            enc = bytes(x ^ ks[i%32] for i, x in enumerate(data))
            tag = hmac.new(self._master_key, enc+nonce, hashlib.sha256).digest()[:16]
            ct = enc + tag
        return base64.b64encode(nonce + ct).decode()

        if not self._master_key: raise SecurityError("No inicializado")
        raw = base64.b64decode(tok); nonce = raw[:self._nonce_len]; ct = raw[self._nonce_len:]
        a = aad.encode() if aad else None
        if CRYPTO and self._aesgcm: return self._aesgcm.decrypt(nonce, ct, a).decode()
        tag, enc = ct[-16:], ct[:-16]
        exp = hmac.new(self._master_key, enc+nonce, hashlib.sha256).digest()[:16]
        if not hmac.compare_digest(tag, exp): raise SecurityError("Integridad comprometida")
        ks = hashlib.sha256(self._master_key + nonce).digest()
        return bytes(x ^ ks[i%32] for i, x in enumerate(enc)).decode()
    def create_session_token(self, uid, role):
        p = json.dumps({"uid":uid,"role":role,"exp":time.time()+self._timeout*60,"iat":time.time()})
        if CRYPTO and self._fernet: return self._fernet.encrypt(p.encode()).decode()
        enc = base64.b64encode(p.encode()).decode()
        sig = hmac.new(self._master_key, enc.encode(), hashlib.sha256).hexdigest()
        return f"{enc}.{sig}"
    def validate_session_token(self, token):
        try:
            if CRYPTO and self._fernet: p = json.loads(self._fernet.decrypt(token.encode()).decode())
            else:
                parts = token.split(".")
                if len(parts) != 2: return None
                enc, sig = parts
                exp = hmac.new(self._master_key, enc.encode(), hashlib.sha256).hexdigest()
                if not hmac.compare_digest(sig, exp): return None
                p = json.loads(base64.b64decode(enc).decode())
            if time.time() > p.get("exp", 0): return None
            return p
        except: return None
    def hash_password(self, password):
        salt = os.urandom(self._salt_len)
        key = hashlib.pbkdf2_hmac("sha256", password.encode(), salt, self._iters, dklen=32)
        return f"{self._iters}${salt.hex()}${key.hex()}"
    def verify_password(self, password, stored):
        try:
            parts = stored.split("$")
            if len(parts) != 3: return False
            iters, salt_h, hash_h = int(parts[0]), bytes.fromhex(parts[1]), bytes.fromhex(parts[2])
            comp = hashlib.pbkdf2_hmac("sha256", password.encode(), salt_h, iters, dklen=32)
            return hmac.compare_digest(comp, hash_h)
        except: return False
    def needs_rotation(self):
        if not self._created: return True
        return (datetime.now() - self._created).days >= self._rot_days
    @staticmethod
    def file_sha256(fp):
        h = hashlib.sha256()
        with open(fp, "rb") as f:
            for c in iter(lambda: f.read(8192), b""): h.update(c)
        return h.hexdigest()
