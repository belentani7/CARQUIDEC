## 3. Blindaje Legal para Redes Automatizadas en 2026

### 3.1 Uso Estricto de APIs Oficiales

**REGLA DE ORO:** Nunca utilices bots de *scraping* agresivo o emuladores de navegador (*puppeteer*, *playwright*) para hacer login con usuario y contraseña y publicar. Esto viola los Términos de Servicio (ToS) de Meta, LinkedIn, TikTok y causa el **baneo inmediato y permanente de la cuenta**.

**Solución legal:**
- Conecta las cuentas únicamente mediante **OAuth 2.0 y APIs oficiales**
- Usa Postiz como intermediario: Postiz maneja la autenticación OAuth con cada plataforma y te expone una API unificada [[111]]
- Alternativas legales: Buffer API, Hootsuite API, Sprout Social API (más caras)

**APIs oficiales por plataforma en 2026:**
- **Meta (Facebook/Instagram):** Meta Graph API v19+ con permisos `pages_manage_posts`, `instagram_content_publish` [[39]]
- **LinkedIn:** LinkedIn Marketing Developer Platform con `Share API` y `UGC Posts API` [[40]]
- **TikTok:** Content Posting API (la más restrictiva, requiere aprobación) [[42]], [[47]]
- **X (Twitter):** X API v2 con tier Free (1,500 tweets/mes) o Basic ($100/mes)
- **YouTube:** YouTube Data API v3 con `youtube.upload` scope

### 3.2 Política de Transparencia e IA (EU AI Act - Artículo 50)

**IMPORTANTE:** El Artículo 50 del EU AI Act entra en vigor el **2 de agosto de 2026** [[22]], [[27]]. Establece obligaciones de transparencia en cuatro situaciones:

1. **Cuando la IA genera contenido sintético** (imágenes, vídeo, audio, texto) [[23]]
2. **Para sistemas de IA generativa** (incluyendo chatbots y asistentes) [[24]]
3. **Cuando se manipula contenido existente** (deepfakes, edición con IA) [[28]]
4. **Cuando la IA interactúa con humanos** (debe declararse que es un bot) [[29]]

**Requisitos específicos para tu agencia:**

- **Etiquetado obligatorio:** Si generas imágenes sintéticas completas con IA (Midjourney, DALL-E, Stable Diffusion) o voces sintéticas (ElevenLabs, PlayHT), debes añadir la etiqueta o metadato de "Contenido generado por IA" [[24]].
- **Formato de etiquetado:** Según el Code of Practice de la UE, el etiquetado debe ser "claro, visible y comprensible" [[30]]. Ejemplos:
  - Watermark visible: "Generado con IA"
  - Metadatos en el archivo (IPTC, XMP)
  - Texto en la descripción del post: "🤖 Contenido asistido por IA"
  - Hashtag: #ContenidoIA o #AIGenerated

- **Exenciones:** El etiquetado NO es obligatorio cuando el contenido asistido por IA es "claramente parte de una obra artística, creativa o satírica" o cuando la asistencia es "marginal" (ej: solo corrección gramatical) [[25]].

**Implementación práctica:**
```python
# Ejemplo de código para añadir metadatos a imágenes generadas
from PIL import Image
from PIL.ExifTags import Base as ExifBase

def add_ai_metadata(image_path, output_path):
    img = Image.open(image_path)
    exif = img.getexif()
    # Añadir marca de contenido IA
    exif[ExifBase.ImageDescription] = "AI-Generated Content - EU AI Act Art.50 Compliant"
    img.save(output_path, exif=exif)
```

### 3.3 Contrato de Tratamiento de Datos (RGPD - Artículo 28)

Si gestionas las cuentas de un tercero (publicas en su nombre, accedes a sus datos de clientes, manejas su CRM), **DEBES** firmar un **Data Processing Agreement (DPA)** según el Artículo 28 del RGPD [[65]], [[67]].

**Requisitos obligatorios del DPA:**

1. **Instrucciones documentadas:** El procesador (tu agencia) solo puede procesar datos personales según las instrucciones documentadas del controlador (tu cliente) [[68]], [[69]].

2. **Confidencialidad:** Las personas autorizadas para procesar los datos deben estar sujetas a obligaciones de confidencialidad [[67]].

3. **Seguridad técnica:** Implementar medidas técnicas y organizativas apropiadas (encriptación, control de acceso, backups) [[72]].

4. **Sub-procesadores:** No puedes contratar a otro procesador (ej: otro freelancer) sin autorización previa y por escrito del controlador [[70]].

5. **Derechos del interesado:** Asistir al controlador para responder a solicitudes de usuarios que ejerzan sus derechos (acceso, rectificación, eliminación) [[71]].

6. **Eliminación de datos:** Al finalizar el contrato, eliminar o devolver todos los datos personales según elección del controlador [[73]].

7. **Auditorías e inspecciones:** Permitir auditorías por parte del controlador o un auditor autorizadoado [[73]].

**Uso para tu agencia:**

```sql
CREATE TABLE clientes (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  nombre TEXT NOT NULL,
  email TEXT UNIQUE NOT NULL,

  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE contenido (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  cliente_id UUID REFERENCES clientes(id),
  tipo_contenido TEXT, -- 'podcast', 'webinar', 'video'
  archivo_url TEXT,
  transcript TEXT,
  created_at TIMESTAMP DEFAULT NOW()
);

CREATE TABLE publicaciones (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  contenido_id UUID REFERENCES contenido(id),
  plataforma TEXT NOT NULL,
  post_content TEXT,
  scheduled_at TIMESTAMP,
  published_at TIMESTAMP,
  post_id_externo TEXT, -- ID de LinkedIn/Instagram/etc
  status TEXT DEFAULT 'pending' -- 'pending', 'published', 'failed'
);
```

    if (request.method === 'POST') {
      const payload = await request.json();
      
      // Validar firma del webhook (seguridad)
      const signature = request.headers.get('X-Webhook-Signature');
      if (!verifySignature(payload, signature, env.WEBHOOK_SECRET)) {

## 8. Riesgos y Mitigación

### **Riesgo 1: Baneo de Cuentas por Uso de APIs**

**Probabilidad:** Baja si usas APIs oficiales
**Impacto:** Alto (pérdida de cliente)
**Mitigación:**
- Usar SIEMPRE OAuth 2.0 y APIs oficiales (nunca scraping)
- Respetar rate limits de cada plataforma
- Monitorear health de cuentas con alertas en Slack/email
- Tener backups: si LinkedIn banea una cuenta, migrar a cuenta alternativa

### **Riesgo 2: Cambios en Algoritmos de Plataformas**

**Probabilidad:** Alta (Meta/TikTok cambian algoritmos cada 2-3 meses)
**Impacto:** Medio (reducción de reach)
**Mitigación:**
- Diversificar plataformas (no depender solo de LinkedIn o Instagram)
- Ajustar prompts de IA basados en tendencias actuales
- Monitorear métricas semanalmente y optimizar horarios/formatos
- Mantener relación cercana con clientes para ajustar expectativas

### **Riesgo 3: Competencia de Agencias Tradicionales**

**Probabilidad:** Alta
**Impacto:** Medio (presión de precios)
**Mitigación:**
- Diferenciarte por velocidad (entrega en 48h vs 2 semanas)
- Diferenciarte por precio ($1,500 vs $5,000 de agencias tradicionales)
- Enfocarte en nichos específicos (podcasters B2B, consultores high-ticket)
- Construir autoridad con contenido propio (demostrar que practicas lo que predicas)

### **Riesgo 4: Problemas Legales por Contenido Generado por IA**

**Probabilidad:** Media (especialmente en Europa con EU AI Act)
**Impacto:** Alto (multas de hasta €30M o 6% de facturación global)
**Mitigación:**
- Etiquetar SIEMPRE contenido sintético según EU AI Act Artículo 50 [[22]], [[27]]
- Tener DPAs firmados con todos los clientes B2B [[65]]
- Incluir cláusula de responsabilidad en contratos (cliente aprueba contenido antes de publicación)
- Usar watermarking y metadatos en imágenes/vídeos generados
